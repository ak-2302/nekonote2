## バックエンドとの通信
### アカウント登録・ログイン
1. フロントエンドでログイン情報を取得する。
2. APIを使用してログイントークンを取得する。
3. APIにトークンを添付してユーザー情報を取得する。
4. ユーザー情報を画面に表示する。

### タイマー
1. フロントエンドでタイマー画面のURLを開く。
2. URLパラメータに付与されているタスクのUUIDを取得し、APIからタスク情報を取得する。
3. タスク情報を画面に表示する。
